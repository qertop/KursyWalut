O projekcie KursyWalut i architekturze systemu

Interaktywna platforma internetowa dedykowana prezentacji, analizie statystycznej oraz monitorowaniu notowań walut obcych publikowanych przez Narodowy Bank Polski. Projekt łączy inżynierię oprogramowania front-endowego z metodami eksploracji i analizy danych finansowych.

1. Założenia i cel realizacji

Celem projektu jest praktyczne wykorzystanie standardów front-endowych: HTML5, CSS3 oraz czystego JavaScript (Vanilla JS), bez uciekania się do ciężkich frameworków programistycznych (takich jak React, Angular czy Vue). Rozwiązanie zostało zaprojektowane z myślą o uruchomieniu w dowolnej typowej przeglądarce internetowej bezpośrednio z systemu plików (plik index.html) bez konieczności instalowania lokalnego serwera HTTP.

2. Architektura witryny (5 logicznych podstron)

Każdy widok realizuje ściśle określone funkcjonalności biznesowe i analityczne

🏠

Strona główna (index.html)

Plik widoku: index.html

Centrum dowodzenia serwisu: dynamiczny podgląd 8 popularnych walut (EUR, USD, GBP, CHF, NOK, SEK, CZK, HUF) ze zmianami 24h, interaktywny kalkulator wymiany walut po kursie z wybranego dnia oraz podgląd mini-wykresu trendu.

📊

Tabela kursów (dane.html)

Plik widoku: dane.html

Zbiór 20 oficjalnych pozycji walutowych NBP (Tabela A i C). Wyposażona w zaawansowane filtry wielokryterialne (wyszukiwanie tekstowe, selektor waluty, zakres dat), szybkie tagi kategorii oraz pełne sortowanie po każdej kolumnie.

📈

Analiza i wykresy (analiza.html)

Plik widoku: analiza.html

Dashboard statystyczny z wyliczonymi wskaźnikami (Min, Max, Średnia, Zmiana %, Rozstęp), interaktywnym wykresem Chart.js ze zmianą typu widoku, rankingiem dynamiki TOP 3 oraz narzędziem porównywarki dwóch walut.

🔔

Alert kursowy (formularz.html)

Plik widoku: formularz.html

Zaawansowany konfigurator powiadomień zawierający 14 różnorodnych kontrolek, pogrupowanych w 3 sekcje fieldset. Posiada walidację HTML5 oraz 3 dodatkowe reguły JS wraz z dynamicznym podsumowaniem na stronie.

ℹ️

O projekcie (o-projekcie.html)

Plik widoku: o-projekcie.html

Metadane projektu, wykaz technologii, szczegółowa specyfikacja źródeł danych NBP, podział ról w zespole projektowym oraz kompletna lista kontrolna spełnienia wymagań regulaminowych.

3. Zastosowane technologie i standardy

HTML5 Semantyka i Dostępność

Struktura oparta na znacznikach semantycznych (header, nav, main, section, article, aside, figure, footer). Pełne powiązanie etykiet label z kontrolkami oraz atrybuty ARIA.

CSS3 Nowoczesny Design System

System zmiennych CSS (Custom Properties), zaawansowane siatki CSS Grid i układy Flexbox, płynne przejścia transition, animacje kluczowe oraz responsywność (4 reguły @media dla urządzeń mobilnych).

Vanilla JS Czysty JavaScript (ES6+)

Manipulacja drzewem DOM przez querySelector, obsługa zdarzeń (click, input, change, submit), walidacja biznesowa, trwałe zapamiętywanie motywu w localStorage i ochrona przed XSS (textContent).

Chart.js Wizualizacja szeregów czasowych

Lekka biblioteka typu open-source do renderowania wykresów notowań w elemencie <canvas>, obsługująca tryby liniowe, słupkowe oraz obszarowe.

4. Źródła danych i metodologia NBP

Serwis korzysta z danych publikowanych przez Narodowy Bank Polski na podstawie ustawy o NBP oraz uchwał Zarządu NBP:

  • Tabela A kursów średnich: Publikowana w każdy dzień roboczy między godziną 11:45 a 12:15. Obejmuje 33 waluty obce kwotowane względem złotego (PLN). Kursy wyliczane są z dokładnością do 4 miejsc po przecinku.
  • Tabela C kursów kupna i sprzedaży: Publikowana w każdy dzień roboczy do godziny 8:15. Definiuje rynkowe kursy transakcyjne oraz pozwala na badanie wielkości spreadu walutowego.
  • Oficjalne API NBP: Dane udostępniane są w formacie JSON i XML pod adresem https://api.nbp.pl/, z zachowaniem pełnej zgodności z archiwum kursów banku centralnego.

5. Zespół projektowy i podział odpowiedzialności

Zgodnie z zasadami określonymi w kontrakcie projektowym (CONTRIBUTING.md), prace zostały podzielone na dwa komplementarne obszary:

Osoba B (Front-end & Design)

Architektura widoków i stylizacja

  • Opracowanie semantycznej struktury 5 plików HTML5 (index.html, dane.html, analiza.html, formularz.html, o-projekcie.html).
  • Implementacja kompletnego arkusza stylów css/style.css (zmienne motywu, Flexbox, Grid, responsywność).
  • Przygotowanie wektorowych grafik SVG w katalogu img/ (logo, ilustracje hero, 20 flag państw).
  • Implementacja logiki walidacji formularza i generowania podsumowania (js/formularz.js).
  • Wdrożenie mechanizmu przełączania motywu jasnego/ciemnego (js/common.js).
Osoba A (Data & Logic)

Logika danych, algorytmy i wykresy

  • Definicja zbioru danych walutowych w tablicy obiektów JavaScript (js/data.js).
  • Algorytmy filtrowania wielokryterialnego i dynamicznego sortowania tabeli notowań (js/table.js).
  • Obliczenia wskaźników statystycznych (Min, Max, Średnia, Zmiana) oraz konfiguracja wykresów (js/analiza.js).
  • Matematyczna logika przeliczania walut w kalkulatorze (js/kalkulator.js).
  • Integracja wywołań API NBP lub lokalnego zbioru rekordów JSON.

Instrukcja uruchomienia projektu

Projekt nie wymaga kompilacji, instalacji środowiska Node.js ani uruchamiania serwera lokalnego. Aby uruchomić aplikację:

  1. Sklonuj lub pobierz repozytorium na dysk komputera.
  2. Otwórz plik index.html w dowolnej nowoczesnej przeglądarce internetowej (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari).
  3. Nawiguj pomiędzy podstronami za pomocą głównego menu umieszczonego w nagłówku strony.
