# KursyWalut

Strona z historycznymi kursami walut – kalkulator przeliczeń i wykres zmian.
Projekt na przedmiot **Aplikacje internetowe**.

> Projekt w trakcie tworzenia.

## Funkcje

- **Kalkulator walut** – przeliczanie kwot po kursie z wybranego dnia
- **Tabela kursów** – filtrowanie po walucie i dacie, sortowanie
- **Analiza** – wykres zmian oraz min, max, średnia i zmiana %
- **Formularz** z walidacją
- **Tryb ciemny** zapamiętywany w przeglądarce

## Podstrony

| Strona | Zawartość |
|---|---|
| `index.html` | kalkulator, mini-wykres, popularne waluty |
| `dane.html` | tabela kursów z filtrami |
| `analiza.html` | wskaźniki i wykres |
| `formularz.html` | formularz z walidacją |
| `o-projekcie.html` | opis i źródła |

## Technologie

HTML5 · CSS3 · JavaScript · [Chart.js](https://www.chartjs.org/)

Dane: [API NBP](https://api.nbp.pl/) (kursy średnie, kupna i sprzedaży).
